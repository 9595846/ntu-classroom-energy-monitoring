# 南通大学教室节能监控方案设计

本项目整理了教室节能监控方案设计报告、MATLAB 分析程序、计算结果和报告生成源码。方案从管理、自动化和信息化三个方面讨论教室照明、风扇、空调及多媒体设备的节能监控。

## 主要内容

- 估算 397 间公共多媒体教室和智慧教室的年度用电量。
- 分析非监管时段的用电浪费、电费和碳排放。
- 设计远传电表、占用及环境传感器、DDC、智能保护装置和边缘网关组成的监控系统。
- 设计课表联动、无人延时关闭、故障降级和告警工单策略。
- 建立数字孪生对象关系和节能量核算方法。
- 提出 30 间教室试点及分阶段推广方案。

## 核心估算结果

| 指标 | 中位估算 |
| --- | ---: |
| 教室数量 | 397 间 |
| 年用电量 | 383.01 万 kWh |

## MATLAB 程序

`matlab/ntu_classroom_energy_analysis.m` 包含以下模块：

1. 年度用电量与非监管浪费估算。
2. 低、中、高情景分析。
3. 空调运行时间与浪费比例敏感性分析。
4. 典型日课表、占用状态和节能控制仿真。
5. 节电收益、碳减排量和静态回收期计算。

运行方法：

```matlab
cd('matlab')
run('ntu_classroom_energy_analysis.m')
```

运行程序会重新生成 CSV 数据表和 PNG 分析图。程序已在 MATLAB 中完成运行验证。

## 报告生成源码

`source/build_report.py` 使用 Python 生成报告并绘制配图。依赖见 `requirements.txt`。在项目根目录运行：

```bash
python source/build_report.py
```

生成报告前请确认脚本中的输出路径符合本机目录结构。

## 数据与设计说明

- 公开资料未披露逐间教室的铭牌功率、课表占用和分项电量，因此报告采用设备功率乘运行时间的工程估算法。
- 397 间为公开资料中的 371 间公共多媒体教室与 26 间公共智慧教室之和。
- 空调是非监管浪费的主要来源，实际建设前应至少连续测量 4 周，并按照课时、天气和开放时间校正基线。
- 智能断路器主要承担电路保护和授权隔离，不作为照明、风扇或空调的频繁控制开关。
- 消防应急照明、疏散指示等消防负荷不得纳入节能切断范围。
